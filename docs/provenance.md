# Provenance

This repository is an independently authored implementation of the publicly
documented MikroTik RouterOS API wire protocol. Its code and tests were written
in this repository; they do not copy the earlier application integration that
motivated the extraction.

The package deliberately contains no database, licensing, worker, deployment,
or application configuration code. The protocol framing and response model are
documented by the public contract and covered by isolated stream tests.
